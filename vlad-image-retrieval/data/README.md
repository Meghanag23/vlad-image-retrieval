# Data

This project uses the **INRIA Holidays** dataset (1,491 images, 500 query groups),
which INRIA makes publicly available.

The images are not committed to this repository because of their size.
To run the code, download the dataset and place the images in `data/holidays/`.

Note: some images in the original release are stored rotated. Use the
rotation-corrected version or fix the orientation before extracting features.
